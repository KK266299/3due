# 频域约束可学习噪声：面向 3D 医学图像的不可学习样本生成方法

## 1. 研究动机

### 1.1 为什么针对 3D 医学图像？

3D 医学图像（如 MRI、CT）具有独特的数据特性，使其在隐私保护场景下面临特殊挑战：

- **层间解剖连续性**：相邻切片之间的解剖结构高度相似，器官边界和组织分布在 z 轴方向上平滑过渡。分割模型正是利用这种层间一致性（inter-slice consistency）来实现准确的 3D 分割。
- **语义冗余性**：由于体素级标注的连续性，模型可以从相邻切片"借用"语义信息，即使单层受到干扰也能通过上下文恢复。
- **频域结构特征**：3D 医学图像在频域中具有明显的各向异性——z 轴（层间）方向的低频能量占主导（反映解剖连续性），而 xy 平面（层内）的高频分量携带边缘和纹理信息。

因此，传统 2D 不可学习样本（Unlearnable Examples, UE）方法直接应用于 3D 数据时效果有限——它们无法针对性地破坏这些 3D 特有的结构先验。

### 1.2 核心思路：破坏层间一致性 + 最大化分割差异

本方法的核心动机是：

1. **破坏层间一致性**：在频域中向 z 轴注入高频扰动，使相邻切片的噪声模式产生剧烈变化，打破分割模型赖以学习的层间平滑先验。
2. **最大化分割差异**：通过在频域中度量干净样本与加噪样本的 logits 差异（FFT L1），迫使噪声在频谱全局范围内最大化预测偏离。
3. **频域可学习约束**：以两个全局可学习标量（z_cutoff, xy_cutoff）自适应控制噪声的频谱分布，在破坏效果与视觉隐蔽性之间取得平衡。

### 1.3 为什么在频域处理？

频域处理相比空间域具有以下优势：

- **解耦 z 轴与 xy 平面**：3D FFT 后，z 轴频率与 xy 平面频率自然分离，可以独立控制层间（z）和层内（xy）的噪声特性。
- **精确的频带控制**：通过截断频率实现对噪声频谱的精细操控——保留 z 轴高频以破坏层间一致性，保留 xy 平面低频以维持空间平滑（视觉不可感知）。
- **全局性**：频域操作天然作用于整个体积，而非逐体素操作，效率更高且能捕捉全局结构。
- **可微分滤波**：使用 sigmoid soft mask 替代硬阈值，使截断频率可通过梯度下降优化。

## 2. 整体架构

```
输入图像 x ──→ NoiseUNet ──→ δ_raw（原始噪声）
                                   │
全局可学习截断频率                    │
(z_cutoff, xy_cutoff) ─────────────┤
                                   ▼
                    FrequencyDomainConstraint
                    (3D FFT → sigmoid mask → 3D IFFT)
                                   │
                                   ▼
                            δ_filtered（频域约束后的噪声）
                                   │
                    SoftROIMask ────┤（可选：ROI 感知加权）
                                   │
                                   ▼
                         δ = clamp(δ_filtered, -ε, ε)
                                   │
                                   ▼
                    x_noisy = clamp(x + δ, 0, 1)
                                   │
                         ┌─────────┴─────────┐
                         ▼                   ▼
                   代理模型 S(·)         干净预测 S(x)
                         │                   │
                         ▼                   ▼
                    logits_noisy        logits_clean
                         │                   │
              ┌──────────┼───────────────────┤
              ▼          ▼                   ▼
         L_seg      L_logits_div        L_z_div
        (DiceCE)    (FFT L1)      (层间多样性)
              │          │                   │
              └──────────┴───────────────────┘
                         │
                    L_total = L_seg + L_logits_div + λ · L_z_div
                         │
                    ┌────┴────┐
                    ▼         ▼
              opt_unet    opt_cutoff
              .step()     .step()
```

## 3. 核心模块详解

### 3.1 NoiseUNet（噪声生成器）

**架构**：基于 MONAI 的 3D UNet，输入输出通道数相同（即输入图像 → 输出同尺寸噪声）。

**关键设计**：
- **NoiseUNetWrapper**：将 UNet 输出通过 `tanh` 激活并乘以 ε（扰动上界），确保噪声幅度始终在 [-ε, ε] 范围内。

```python
def forward(self, x):
    return torch.tanh(self.unet(x)) * self.epsilon
```

- **参数化噪声生成**：不同于 PGD 等逐像素优化方法，NoiseUNet 以图像为条件生成噪声，能捕捉输入图像的结构信息，生成具有空间自适应性的扰动模式。

**配置参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| channels | [16, 32, 64, 128] | UNet 各层通道数 |
| strides | [2, 2, 2] | 下采样步长 |
| num_res_units | 1 | 残差单元数 |
| act | LEAKYRELU | 激活函数 |
| norm | INSTANCE | 归一化方式 |
| epsilon | 8/255 | 噪声幅度上界 |

### 3.2 GlobalLearnableCutoff（全局可学习截断频率）

**设计动机**：截断频率决定了噪声的频谱分布特征。固定值难以适应不同数据集和训练阶段，因此将 z_cutoff 和 xy_cutoff 设为两个全局 `nn.Parameter` 标量，通过梯度下降联合优化。

**参数化方式**：
- 内部以 logit 空间存储（无约束实数）
- 通过 sigmoid 映射到指定范围：
  - `z_cutoff ∈ [0.01, 0.45]`（归一化频率）
  - `xy_cutoff ∈ [0.05, 0.45]`

```python
def forward(self):
    z = sigmoid(z_logit) * (z_max - z_min) + z_min
    xy = sigmoid(xy_logit) * (xy_max - xy_min) + xy_min
    return z, xy
```

**物理含义**：
- `z_cutoff`：z 轴方向的截断频率。频率 ≥ z_cutoff 的分量被保留（高通），这些高频分量对应层间的剧烈变化。
- `xy_cutoff`：xy 平面的截断频率。频率 ≤ xy_cutoff 的分量被保留（低通），保持层内噪声的空间平滑性。

### 3.3 FrequencyDomainConstraint（频域约束模块）

这是方法的核心模块，实现频域中的各向异性滤波。

**处理流程**：
1. 对噪声 δ 执行 3D FFT：`δ_fft = FFT3D(δ)`
2. 构造两个可微分的 sigmoid mask：
   - **M_z（z 轴高通）**：`sigmoid((|f_z| - z_cutoff) / σ_z)`
     当 |f_z| > z_cutoff 时趋近 1，保留 z 轴高频
   - **M_xy（xy 平面低通）**：`sigmoid((xy_cutoff - r_xy) / σ_xy)`
     当 r_xy < xy_cutoff 时趋近 1，保留 xy 低频
3. 逐元素相乘：`δ_fft_filtered = δ_fft * M_z * M_xy`
4. 3D IFFT 回到空间域：`δ_filtered = IFFT3D(δ_fft_filtered).real`

**DC 分量校正**：
- DC 分量（零频）对应图像均值，需要特殊处理
- 通过校正因子将 DC 分量缩放至 0.1，避免噪声改变图像整体亮度

**可微分性**：
- 使用 sigmoid soft mask 替代 `torch.where` 硬阈值，确保梯度可以通过截断频率反向传播
- σ_z 和 σ_xy 控制过渡带的平滑程度

### 3.4 SoftROIMask（ROI 感知软掩码）

**目的**：将噪声集中在分割目标区域（如肿瘤、器官），提高噪声的有效性。

**处理步骤**：
1. 从标签生成二值 mask（前景 > 0）
2. 膨胀操作（3D max pooling），扩展 ROI 边界
3. 3D 高斯模糊，生成软边缘过渡
4. 归一化至 [0, 1]

**效果**：噪声在 ROI 区域强度最大，向外平滑衰减至零，兼顾破坏效果与隐蔽性。

### 3.5 LogitsDivergenceLoss（FFT L1 模式）

**设计动机**：直接在频域中度量干净预测与加噪预测的差异，迫使噪声在频谱全局范围内最大化预测偏离。

**计算过程**：
```
diff = logits_noisy - logits_clean          # [B, C, D, H, W]
diff_fft = FFT3D(diff)                       # 频域差异
divergence = mean(|diff_fft|)                # L1 范数
loss = -weight * divergence                  # 取负号以最大化
```

**为什么选择 FFT L1**：
- 在频域中度量差异可以捕捉全局结构性偏差，而非仅关注逐体素误差
- L1 范数对频谱中的稀疏差异更敏感，适合捕捉局部频带的显著偏移
- 与频域约束模块形成协同——噪声的频域特性与损失的度量空间一致

### 3.6 Z-Diversity 正则化

**设计动机**：显式鼓励相邻切片的噪声模式差异最大化，直接破坏层间一致性。

**计算过程**：
```
delta_fft_2d = FFT2D(delta)                   # 对每个 slice 做 2D FFT
delta_fft_mag = |delta_fft_2d|                # 幅度谱 [B, C, D, H, W]
slice_diff = mag[:,:,1:,:,:] - mag[:,:,:-1,:,:]  # 相邻 slice 差异
l2_per_pair = sqrt(sum(slice_diff^2))         # L2 距离
z_diversity = mean(l2_per_pair)               # 平均层间多样性
```

**在损失中的作用**：
- `L_z_div = -λ * z_diversity`（取负号以最大化多样性）
- 迫使噪声生成器为相邻切片生成频谱差异尽可能大的噪声模式

## 4. 三个损失函数的协同设计

| 损失函数 | 公式 | 作用 | 针对的 3D 特性 |
|----------|------|------|---------------|
| **L_seg** | DiceCE(S(x+δ), y) | 确保代理模型在加噪样本上仍能"学习"，维持对抗训练的稳定性 | 保证噪声不会导致训练崩溃 |
| **L_logits_div** | -mean(\|FFT3D(logits_noisy - logits_clean)\|) | 最大化频域中预测差异，使噪声在频谱全局范围内扰乱模型输出 | 破坏 3D 分割的全局一致性 |
| **L_z_div** | -λ · mean(L2(FFT2D_slice[i+1] - FFT2D_slice[i])) | 最大化相邻切片噪声频谱差异 | 直接破坏层间解剖连续性 |

**总损失**：
```
L_total = L_seg + L_logits_div + λ_z · L_z_div
```

**协同逻辑**：
- L_seg 维持训练循环的可行性（代理模型需要持续更新）
- L_logits_div 在频域全局层面最大化预测偏离
- L_z_div 在 z 轴维度上施加结构性约束，确保噪声特异性地破坏层间一致性

## 5. 训练流程

### 5.1 双循环训练（S-step / N-step）

**S-step（代理模型更新）**：
1. 从噪声后端读取当前噪声 δ
2. 生成加噪样本 x_noisy = x + δ
3. 代理模型前向传播，计算 DiceCE loss
4. 更新代理模型参数

**N-step（噪声 + 截断频率更新）**：
1. 冻结代理模型
2. NoiseUNet 生成原始噪声 δ_raw
3. 全局截断频率模块输出 (z_c, xy_c)
4. 频域约束模块滤波：δ_filtered
5. ROI mask 加权 + clamp
6. 计算三个损失并求和
7. 反向传播，同时更新 NoiseUNet 参数和截断频率参数
8. 将最终噪声写入噪声后端

### 5.2 关键实现细节

- **截断频率独立优化器**：z_cutoff 和 xy_cutoff 使用单独的 Adam 优化器，学习率可通过 `cutoff_lr_scale` 缩放
- **每 epoch 日志**：记录截断频率的当前值及其相对初始值的变化量（Δ），便于观察频率参数的演化趋势
- **无需逐样本循环**：截断频率是全局标量（非逐样本预测），所有样本共享同一组滤波参数，支持标准 batch forward

## 6. 设计总结

本方法的核心创新在于：**将 3D 医学图像的层间一致性识别为分割模型的关键学习先验，并通过频域各向异性滤波 + 可学习截断频率的方式，精准地、自适应地破坏这一先验**。

频域处理使得 z 轴（层间）和 xy 平面（层内）的噪声特性可以独立控制：
- z 轴高频 → 层间噪声剧变 → 破坏解剖连续性
- xy 平面低频 → 层内噪声平滑 → 维持视觉隐蔽性

三个损失函数从不同层面协同工作：分割损失维持训练稳定性，logits 散度损失最大化频域预测偏离，z 轴多样性损失直接攻击层间一致性。
