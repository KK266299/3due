## Abstract（结构化摘要）

**写作要点**：不要上来就说"我们提出了一种方法"，而是从问题出发。

1. **问题引入**（1-2 句）：3D 医学图像分割模型的训练依赖于体积数据中固有的层间解剖连续性和空间语义一致性；现有不可学习样本方法主要面向 2D 自然图像，忽视了 3D 医学数据的体积结构特性。
2. **关键洞察**（1 句）：分割模型通过层间一致性学习 3D 上下文，而频域中 z 轴低频主导的频谱结构恰恰编码了这种一致性。
3. **方法概述**（2-3 句）：我们提出频域各向异性扰动框架，通过可学习的截断频率自适应地在 z 轴注入高频扰动（破坏层间一致性），同时约束 xy 平面噪声的低频特性（维持视觉隐蔽性）；联合优化分割损失、频域 logits 散度与层间多样性正则化。
4. **实验结果**（1-2 句）：在 BraTS19/FLARE21/KiTS19 上的实验表明，方法使受害模型 Dice 显著下降，且对多种模型架构具有迁移性。

## 1. Introduction

### 写作逻辑线（非流程罗列，而是论证链）

**第一段：3D 医学图像分割的数据隐私问题**
- 3D 医学图像（MRI、CT）包含高度敏感的患者信息
- 深度学习分割模型的成功依赖大量标注数据 → 未经授权的模型训练威胁数据隐私
- 不可学习样本（UE）作为一种主动防御手段：在数据发布前添加不可感知扰动，使训练在该数据上的模型性能大幅下降

**第二段：现有 UE 方法的局限性——缺乏对 3D 特性的针对**
- 现有 UE 方法（Error-Minimizing, TAP, LSP, SEP 等）主要为 2D 自然图像分类设计
- 直接应用于 3D 医学分割存在根本性不足：
  - **忽视体积结构**：逐切片独立加噪，未考虑 z 轴维度的信息关联
  - **未攻击 3D 先验**：分割模型利用层间解剖连续性、3D 上下文信息进行预测，而 2D 方法无法有效破坏这些 3D 特有的学习信号
  - **分割 vs 分类**：分割任务的像素级密集预测特性要求噪声具有空间结构性，而非仅仅改变全局特征分布

**第三段：核心洞察——层间一致性是 3D 分割模型的关键学习先验**
- 3D 医学图像的核心特征：解剖结构在 z 轴方向平滑过渡，相邻切片共享高度相似的语义内容
- 分割模型（3D UNet 等）的 3D 卷积核显式地建模层间关系，通过跨切片的上下文聚合实现准确分割
- **关键论点**：如果能够打破这种层间一致性，使相邻切片呈现相互矛盾的语义信号，分割模型将无法有效学习 3D 空间关系
- 频域视角：层间一致性在频域中表现为 z 轴低频主导——相邻切片变化缓慢 → z 轴频谱集中在低频。注入 z 轴高频 = 制造层间突变

**第四段：方法概述与贡献总结**
- 我们提出 XXX（方法名），一种针对 3D 医学图像特性的频域不可学习样本生成框架
- **贡献列表**（3-4 条）：
  1. 首次从层间一致性破坏的角度设计 3D 医学图像的不可学习样本，提出频域各向异性扰动策略
  2. 提出可学习的全局截断频率参数，自适应地平衡 z 轴破坏强度与 xy 平面隐蔽性
  3. 设计频域 logits 散度损失（FFT L1）与层间多样性正则化，从预测层面和噪声结构层面协同攻击 3D 分割
  4. 在三个 3D 医学分割基准上验证方法有效性，对多种模型架构展现跨架构迁移性

## 3. Method

### 3.1 Problem Formulation

- 形式化定义 3D 不可学习样本生成问题
- 明确优化目标：生成扰动 δ 使得在 (x+δ, y) 上训练的模型 f 在干净测试集上性能最差
- 约束条件：||δ||∞ ≤ ε

### 3.2 Analysis: Why Inter-Slice Consistency Matters

> **这一节是论文的核心论证，不应该省略**

- **定量分析**：展示 3D 医学图像在频域中的频谱分布特征（z 轴 vs xy 平面）
- **实验佐证**：对比破坏层间一致性 vs 随机噪声对分割性能的影响差异
- **理论直觉**：3D 卷积核的层间感受野如何依赖输入的层间平滑性

### 3.3 Frequency-Domain Anisotropic Perturbation

**3.3.1 Noise Generation Network**
- 条件噪声生成：以输入图像为条件，通过 3D UNet 生成结构化噪声
- Tanh 约束确保幅度控制

**3.3.2 Learnable Spectral Constraint**
- 全局可学习截断频率 (z_cutoff, xy_cutoff) 的设计动机与参数化
- 频域各向异性滤波：z 轴高通 × xy 平面低通
- Sigmoid soft mask 的可微分设计
- **重点论述**：为什么不固定截断频率，而是让它自适应学习？
  - 不同数据集 / 训练阶段的最优频率分布不同
  - 可学习参数能够在破坏效果与视觉质量之间动态寻找最优折中

**3.3.3 ROI-Aware Noise Weighting**
- 简要说明 SoftROIMask 的作用，噪声集中于分割目标区域

### 3.4 Loss Functions

> **写作重点：不是罗列三个损失，而是论证为什么需要它们、它们如何从不同维度攻击 3D 分割**

**3.4.1 Segmentation Loss (L_seg)**
- DiceCE loss，作用于代理模型
- 维持对抗训练的稳定性，确保代理模型持续提供有效的梯度信号

**3.4.2 Frequency-Domain Logits Divergence (L_logits)**
- 在频域中度量 logits 差异（FFT L1）
- **论证角度**：
  - 为什么在频域而非空间域度量？频域捕捉全局结构偏差，空间域 L1 仅关注逐体素差异
  - 为什么用 L1 而非 L2？L1 对频谱中的稀疏但显著的偏移更敏感
  - 与频域约束模块的协同：噪声在频域中被塑形，损失也在频域中度量，形成一致的优化空间

**3.4.3 Inter-Slice Diversity Regularization (L_z_div)**
- 通过 2D FFT 逐切片分析 → 计算相邻切片频谱的 L2 差异
- **论证角度**：
  - 这是对层间一致性破坏的直接度量
  - 为什么在频域而非空间域计算层间差异？频域幅度谱更稳定地反映切片的纹理结构，避免被空间平移或微小偏移干扰
  - 与 L_logits 的互补性：L_logits 从预测层面施压，L_z_div 从噪声结构层面约束

## 4. Experiments

### 4.1 Experimental Setup

**数据集**：
- BraTS19（脑肿瘤，4 类，4 模态 MRI）
- FLARE21（腹部器官分割）
- KiTS19（肾脏肿瘤分割）

**代理模型与受害模型**：
- 代理模型：3D UNet（与噪声生成共同训练）
- 受害模型：UNet, Attention UNet, UNet++, TransUNet 等（验证跨架构迁移性）

**Baseline 方法**：
- Clean（无扰动）
- Random Noise
- Min-Min / TAP / LSP / SEP / PUE
- 2D UE 方法直接应用于 3D

**评价指标**：
- Dice Score（越低 → UE 越有效）
- HD95
- 可视化分析

### 4.2 Main Results

- **核心实验表格**：各方法在三个数据集上的 Dice 对比
- **跨架构迁移性**：代理用 UNet 训练噪声，受害用其他架构训练
- **关键发现**：突出本方法相比 2D 方法在 3D 数据上的显著优势
