## Abstract（结构化摘要）

**写作要点**：从问题出发，不要上来就说"我们提出了一种方法"。

1. **问题引入**（1-2 句）：3D 医学图像分割模型的训练依赖于体积数据中固有的层间解剖连续性；现有不可学习样本方法主要面向 2D 自然图像，未考虑 3D 体积数据的结构特性与分割任务的密集预测需求。
2. **关键洞察**（1 句）：3D 分割模型通过 3D 卷积跨切片聚合上下文，其性能高度依赖相邻切片间的解剖一致性——这种层间一致性是可被精准攻击的脆弱先验。

4. **实验结果**（1-2 句）：在 BraTS19/FLARE21/KiTS19 三个 3D 医学分割基准上的实验表明，本方法显著降低受害模型的 Dice 性能，并对多种架构展现跨模型迁移性。

## 1. Introduction

> **核心论证链**：3D 分割依赖层间一致性 → 现有 UE 忽视该先验 → 我们从频域损失角度精准攻击

### 第一段：3D 医学图像的数据保护需求

- 3D 医学影像（MRI、CT）承载高度敏感的患者隐私信息
- 深度学习分割模型（3D UNet、nnUNet 等）在脑肿瘤分割、器官分割等任务上取得突破性进展，但其成功依赖大量标注体积数据
- 未经授权的模型训练构成数据滥用风险 → 引出 **不可学习样本（Unlearnable Examples, UE）** 作为一种主动式数据保护策略：在发布前向数据注入不可感知扰动，使在该数据上训练的模型无法学到有效的分割能力

### 第二段：现有 UE 方法的根本性不足——忽视 3D 体积结构

- 回顾现有代表性 UE 方法：Error-Minimizing（Huang et al.）、TAP（Fowl et al.）、LSP、SEP 等
- 这些方法的共同局限性：
  - **为 2D 分类设计**：噪声作用于单张图像的全局特征分布，无法感知体积数据沿 z 轴的信息流动
  - **未攻击 3D 先验**：3D 分割模型的核心学习信号——层间解剖连续性、跨切片语义一致性——完全未被触及
  - **分割 ≠ 分类**：密集像素级预测要求噪声具有空间结构性和语义针对性，而非仅改变全局统计量
- **问题陈述**：直接将 2D UE 方法应用于 3D 医学分割时，效果有限——模型仍可通过层间上下文"修复"单切片噪声带来的干扰

### 第三段：核心洞察——层间一致性是 3D 分割的可攻击先验

> 这一段是全文的理论基石，需要充分展开论证

- **3D 医学图像的固有特性**：
  - 解剖结构在 z 轴方向平滑过渡——肝脏、肿瘤等器官的形态在相邻切片间高度相似
  - 这种连续性不是巧合，而是物理采集过程（逐层扫描、各向同性/各向异性体素）的直接结果
  - 从频域视角：层间变化缓慢 = z 轴频谱能量集中在低频

- **分割模型如何利用这一先验**：
  - 3D 卷积核（如 3×3×3）显式建模层间关系，通过跨切片的特征聚合提升分割精度
  - 编码器-解码器架构（3D UNet）在多尺度上利用层间一致性进行上下文推理
  - 这意味着：**如果相邻切片呈现相互矛盾的语义信号，3D 卷积核将接收到混乱的输入，模型无法建立有效的空间表征**

- **关键论点**：层间一致性既是 3D 分割的力量来源，也是其可被精准攻击的脆弱点。破坏这种一致性 = 从根基上瓦解 3D 分割模型的学习能力

### 第四段：我们的方法与贡献

- 我们提出 **XXX**（方法名），一种针对 3D 医学图像体积结构特性的不可学习样本生成方法
- 方法的核心思路：
  - 以输入图像为条件，通过噪声生成网络产生结构化扰动，结合 ROI 感知机制聚焦分割目标区域
  - 设计两个频域感知的损失函数——从 **模型预测层面**（FFT L1 logits 散度）和 **噪声结构层面**（层间频谱多样性）——双重驱动噪声优化，使其精准攻击层间一致性
- **贡献列表**（3 条）：
  1. 首次从层间一致性破坏的角度分析 3D 分割模型的脆弱性，并据此设计针对 3D 医学图像的不可学习样本方法
  2. 提出频域 logits 散度损失（FFT L1）与层间频谱多样性正则化（Z-Diversity），分别从预测差异最大化和噪声结构层间去一致化两个维度协同优化
  3. 在三个 3D 医学分割基准（BraTS19、FLARE21、KiTS19）上验证方法有效性，展现跨架构迁移性

## 2. Methodology

### 2.1 Problem Formulation

- 形式化定义
  - 训练集 $\mathcal{D} = \{(x_i, y_i)\}$，其中 $x_i \in \mathbb{R}^{C \times D \times H \times W}$ 为 3D 体积，$y_i \in \{0,...,K\}^{D \times H \times W}$ 为体素级标签
  - 目标：学习扰动 $\delta_i$ 使得在 $\{(x_i + \delta_i, y_i)\}$ 上训练的分割模型 $f_\theta$ 在干净测试集上性能最差
  - 约束：$\|\delta_i\|_\infty \leq \epsilon$，保证视觉不可感知性
- Bi-level 优化框架引出：
  - 外层：优化噪声生成器参数 $\phi$（NoiseUNet），最小化"模型可学习性"
  - 内层：代理模型 $S_\psi$ 在加噪数据上正常训练，提供梯度信号

### 2.2 Conditional Noise Generation

> **论证角度**：为什么用网络生成噪声而非逐像素 PGD？

**2.2.1 NoiseUNet：结构化噪声生成器**

- 与 PGD（per-pixel optimization）的区别：
  - PGD 为每个体素独立优化扰动，噪声缺乏空间结构
  - NoiseUNet 以输入图像为条件 → 噪声与图像内容相关联 → 更有针对性
  - 网络隐式编码了输入图像的结构先验（边缘、区域分布），使噪声具有空间自适应性
- 架构选择：3D UNet（MONAI 实现），输入/输出通道相同
- 幅度约束：$\delta = \tanh(\text{UNet}(x)) \cdot \epsilon$，确保 $\|\delta\|_\infty \leq \epsilon$

**2.2.2 ROI-Aware Soft Masking**

- **动机**：3D 医学分割的目标区域（肿瘤、器官）通常仅占体积的少部分。将噪声集中在目标区域及其边界附近，既提高扰动效率（不浪费预算在无关背景上），又增强隐蔽性（背景区域无扰动）
- 处理流程：
  - 由标签生成前景 mask → 形态学膨胀（扩展边界） → 3D 高斯平滑（软过渡） → 归一化至 [0,1]
- 最终噪声：$\delta = \delta_{\text{raw}} \odot M_{\text{ROI}}$

### 2.3 Frequency-Domain Driven Loss Design

> **这是本文的核心贡献章节。写作原则：不是罗列三个损失函数，而是论证为什么需要它们、它们如何从不同维度攻击 3D 分割。每个损失都要回扣到 3D 医学图像特性和层间一致性破坏上。**

**2.3.1 为什么在频域设计损失？**

在深入介绍具体损失之前，首先论证频域损失的动机：

- 3D 医学图像的层间一致性在频域中有清晰的表征：z 轴低频主导（相邻切片变化缓慢）
- 频域提供了一个统一的度量空间，能同时捕捉：
  - **全局结构偏差**：频谱的整体分布变化（vs 空间域逐体素差异只反映局部偏移）
  - **层间变异模式**：通过逐切片 2D FFT，可以在频域中精确度量相邻切片噪声模式的差异程度
- 频域度量对空间平移和微小几何偏移具有鲁棒性（幅度谱平移不变），更稳定地反映结构性变化

**2.3.2 Segmentation Loss $\mathcal{L}_{\text{seg}}$**

- DiceCE loss 作用于代理模型在加噪样本上的预测
- **作用**：不是为了"攻击"，而是为了维持 bi-level 优化的稳定性
  - 代理模型需要在加噪数据上持续学习（虽然是被噪声误导的学习），才能为噪声优化提供有意义的梯度信号
  - 如果代理模型完全崩溃 → 梯度消失 → 噪声优化失去方向
- 在总损失中的角色："锚定项"，确保训练循环不发散

**2.3.3 Frequency-Domain Logits Divergence $\mathcal{L}_{\text{logits}}$ (FFT L1)**

- **目标**：从模型预测层面最大化噪声造成的分割差异

- **计算**：
  $$\mathcal{L}_{\text{logits}} = -\frac{1}{|\Omega|} \sum_{\omega \in \Omega} \left| \mathcal{F}_{3D}\left[ S(x+\delta) - S(x) \right](\omega) \right|$$
  其中 $\mathcal{F}_{3D}$ 为 3D FFT，$\Omega$ 为频域采样点集

- **论证——为什么在频域而非空间域度量 logits 差异？**
  - 空间域 L1/L2 仅关注逐体素差异的平均值，容易被局部高强度差异主导，而忽视分布在全局的结构性偏差
  - FFT 将空间域差异分解到频域 → L1(|FFT(diff)|) 等价于度量预测偏差在所有频带上的总能量
  - 这意味着噪声被驱动去在**所有空间频率尺度**上制造预测偏差——既破坏大尺度（低频）的区域级分割，也破坏小尺度（高频）的边界精度
  - 对于 3D 医学分割尤其重要：分割质量同时取决于器官整体形态（低频）和边界精度（高频）

- **为什么选择 L1 而非 L2？**
  - L1 范数对频谱中的稀疏但显著的偏移更加敏感
  - 在频域中，有意义的结构性破坏往往集中在特定频带（如 z 轴高频），L1 不会被其他频带的微小变化稀释

**2.3.4 Inter-Slice Spectral Diversity $\mathcal{L}_{\text{z-div}}$**

- **目标**：从噪声结构层面直接破坏层间一致性

- **计算**：
  - 对噪声 $\delta$ 的每个 z-slice 做 2D FFT → 得到逐切片幅度谱
  - 计算相邻切片幅度谱的 L2 距离 → 取均值
  $$\mathcal{L}_{\text{z-div}} = -\frac{1}{D-1} \sum_{d=1}^{D-1} \left\| |\mathcal{F}_{2D}(\delta^{(d+1)})| - |\mathcal{F}_{2D}(\delta^{(d)})| \right\|_2$$
  取负号以最大化层间多样性

- **论证——为什么这个损失直接攻击 3D 分割的核心？**
  - 3D 卷积核在 z 轴方向的感受野通常为 3（如 3×3×3 kernel）→ 它聚合相邻 3 个切片的特征
  - 如果相邻切片的噪声频谱差异很大 → 卷积核接收到的输入在 z 轴方向剧烈震荡 → 特征提取产生混乱
  - 这等效于在特征空间注入 z 轴高频信号 → 打破了模型赖以学习的层间平滑假设

- **论证——为什么在频域而非空间域计算层间差异？**
  - 空间域的逐体素差异容易受到噪声幅度和空间偏移的干扰
  - 幅度谱是平移不变的 → 更稳定地反映切片的纹理和结构特征
  - 频域差异直接对应"纹理模式的变化"，这正是我们希望最大化的目标

**2.3.5 总损失与协同机制**

$$\mathcal{L} = \mathcal{L}_{\text{seg}} + \mathcal{L}_{\text{logits}} + \lambda \cdot \mathcal{L}_{\text{z-div}}$$

- 三个损失从不同层面形成协同：

| 损失 | 作用层面 | 攻击维度 | 针对的 3D 特性 |
|------|---------|---------|---------------|
| $\mathcal{L}_{\text{seg}}$ | 训练稳定性 | 维持梯度信号 | - |
| $\mathcal{L}_{\text{logits}}$ | 模型预测 | 全频带预测偏离 | 同时破坏整体形态与边界精度 |
| $\mathcal{L}_{\text{z-div}}$ | 噪声结构 | 层间频谱去一致化 | 直接攻击层间解剖连续性 |

- **互补性论证**：
  - $\mathcal{L}_{\text{logits}}$ 告诉噪声"让预测尽可能偏离"，但不指定偏离的方式
  - $\mathcal{L}_{\text{z-div}}$ 告诉噪声"相邻切片的纹理模式要尽可能不同"，提供了结构性约束
  - 二者结合 → 噪声不仅在效果上最大化分割差异，在结构上也精准攻击 3D 特有的层间一致性

### 2.4 Bi-Level Optimization

- **S-step（代理模型更新）**：冻结噪声生成器，代理模型在加噪样本上正常训练（DiceCE loss）
- **N-step（噪声优化）**：冻结代理模型，通过 $\mathcal{L}$ 反向传播更新 NoiseUNet 参数
- 交替执行，每 epoch 内先 S-step 再 N-step

> 简要说明即可，bi-level optimization 不是本文的创新点，不需过多篇幅

### 3.3 Ablation Study

> **消融实验的核心目的：验证每个设计选择的必要性和贡献度**

| 消融配置 | 验证目的 | 预期发现 |
|----------|---------|---------|
| Full method | 基线 | - |
| w/o $\mathcal{L}_{\text{logits}}$ | FFT L1 logits 散度的贡献 | 移除后 Dice 回升 → 频域预测偏离驱动是必要的 |

| 不同 $\epsilon$ 值 | 扰动幅度的影响 | 展示效果-隐蔽性权衡 |

## 写作风格提醒

1. **避免流程化描述**（"首先...然后...最后..."）：每一节以**论证链**为主线，回答"为什么"而非仅描述"怎么做"
2. **3D 针对性贯穿始终**：每个设计选择必须回扣 3D 医学图像特性（层间一致性、解剖连续性、3D 卷积的感受野机制）
3. **损失函数是核心章节**：不要写成三个损失的并列罗列，而是构建从"为什么频域" → "预测层面攻击" → "结构层面攻击" → "协同机制"的递进论证
4. **实验分析重质不重量**：消融实验的每一行都要有明确的论证目的，可视化要服务于核心论点（层间一致性破坏）

## MICCAI 格式注意事项

- 页数限制：8 页正文 + 2 页参考文献（Springer LNCS 格式）
- 正文简洁，补充实验可放 Supplementary Material
- 强调临床意义（数据保护 → 促进数据共享 → 惠及医学 AI 发展）
- 参考文献覆盖 MICCAI / TMI / MedIA / CVPR / NeurIPS 主流期刊会议
