## 1. 研究动机

### 1.1 问题背景：医学图像数据的隐私保护

医学图像数据（CT、MRI 等）包含大量患者隐私信息。当医疗数据集被公开发布或共享后，恶意方可能利用这些数据训练高精度的医学图像分割（Medical Image Segmentation, MIS）模型，进而在未经授权的情况下对患者影像进行自动化分析。这构成了严重的数据滥用风险。

**不可学习样本（Unlearnable Examples, UE）** 提供了一种数据层面的主动防御机制：在发布数据前，对每张图像施加人眼不可感知的微小扰动（perturbation），使得任何下游模型在这些"被保护"数据上训练后，**无法学到有效的分割能力**。

如附图所示，整体流程为：

```
┌──────────────────────────────────────────────────────────────────┐
│                        正常流程（无保护）                          │
│                                                                  │
│  MIS 数据集 ──→ 训练 MIS 模型 ──→ 测试：DSC = 82.18% ✓          │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                     UMed 保护流程                                 │
│                                                                  │
│  MIS 数据集 ──→ UMed 生成扰动 ──→ 受保护数据集                    │
│                                                                  │
│  受保护数据集 ──→ 训练 MIS 模型 ──→ 测试：DSC = 6.80% ✗          │
└──────────────────────────────────────────────────────────────────┘
```

- 在干净数据上训练的模型能够正确分割（DSC = 82.18%）
- 在受保护数据上训练的模型完全失效（DSC = 6.80%），近乎随机猜测
- 扰动幅度极小（ε = 4/255），人眼无法分辨原图与受保护图像的区别

### 1.2 核心攻击目标

本方法的两个核心攻击维度：

**（a）破坏层间一致性（Inter-slice Consistency Disruption）**

3D 医学图像的本质特征是相邻层（slice）之间存在强烈的空间连续性——解剖结构在 Z 轴方向上平滑过渡。3D 分割模型（如 3D U-Net）依赖这种层间一致性来建立体积化的语义理解。我们的方法通过在 Z 轴方向注入**高频变化**的噪声，使得相邻层的扰动模式截然不同，从根本上打破模型对层间连续性的依赖。

**（b）最大化分割差异（Segmentation Divergence Maximization）**

扰动的最终目的是使分割模型在受保护数据上训练时输出完全错误的预测。我们通过一个代理模型（surrogate model）优化噪声，使得代理模型在扰动图像上的分割 loss（DiceCE Loss）被最大化——即噪声被设计为**让分割变得尽可能困难**。

## 2. 为什么针对 3D 医学图像

### 2.1 3D 医学图像的独特结构

与自然图像（2D）不同，3D 医学图像具有以下特性：

| 特性 | 说明 | 对 UE 方法的意义 |
|------|------|------------------|
| **层间连续性** | 相邻 slice 的解剖结构高度相似 | 这是模型的核心先验，破坏它可以瓦解 3D 学习 |
| **各向异性分辨率** | Z 轴分辨率通常远低于 XY 平面 | Z 轴信息更脆弱，更容易被扰动影响 |
| **体积语义** | 器官跨越多个 slice，模型需要 3D 上下文 | 层间不一致的扰动会破坏体积语义的完整性 |
| **数据量大** | 单个样本 [D, H, W] 体积庞大 | 需要内存高效的扰动生成策略 |

### 2.2 3D 模型的脆弱性分析

3D 分割模型（如 3D U-Net、VNet）通过 3D 卷积核学习体积特征。它们的关键假设是：

```
假设：Z 轴方向上的特征变化是平滑、可预测的

现实（被扰动后）：Z 轴噪声模式剧烈变化 → 3D 卷积提取到的特征充满伪影
                  → 模型学到的是噪声模式而非解剖结构
                  → 在干净测试数据上完全失效
```

关键洞察：**3D 模型的优势（利用层间信息）恰恰是其最大的脆弱点**。如果层间信息被污染，模型不仅无法受益，反而会被误导。

### 2.3 为什么 2D 方法不够用

传统 2D 不可学习样本方法（如对每个 slice 独立加噪）忽略了 Z 轴维度：

- 独立加噪可能仍保持层间统计一致性，3D 模型仍能提取有用特征
- 没有针对性地破坏层间关系，攻击效果有限
- 不考虑 3D FFT 的频域特性，无法精确控制扰动的空间频率分布

## 3. 为什么选择频域处理

### 3.1 频域 vs 空域：控制力的差异

在空间域（spatial domain）中，直接操作像素值只能控制局部的强度变化，很难精确控制噪声的**空间频率特性**。而在频率域（frequency domain）中，我们可以独立、精确地控制不同方向、不同尺度上的频率成分。

```
空间域操作：
  pixel[x, y, z] += noise    → 只知道"在哪里加了多少"
                               → 无法直接控制"加的噪声变化快不快"

频率域操作：
  FFT(noise) × Mask → IFFT   → 精确控制"Z 方向变化多快"
                               → 精确控制"XY 平面内变化多快"
                               → 解耦方向与尺度
```

### 3.2 频域分离的核心优势

3D FFT 将信号分解为三个正交方向的频率成分 `(f_z, f_y, f_x)`。我们利用这一点实现**方向解耦**的频率控制：

**Z 轴高通滤波（High-Pass on Z-axis）**

```
目的：保留 Z 轴高频 → 相邻 slice 的噪声差异大
效果：层间一致性被破坏

频率域：|f_z| < z_cutoff 的成分被衰减
        |f_z| ≥ z_cutoff 的成分被保留

空间域等效：相邻 slice 的噪声模式差异大、变化剧烈
```

**XY 平面低通滤波（Low-Pass on XY-plane）**

```
目的：保留 XY 低频 → 每个 slice 内部噪声平滑
效果：扰动不可感知 + 难以通过简单去噪消除

频率域：r_xy > xy_cutoff 的成分被衰减
        r_xy ≤ xy_cutoff 的成分被保留

空间域等效：每张 slice 上的噪声呈现大范围的平滑变化，没有高频纹理
```

### 3.3 为什么这种组合特别有效

两个滤波器的组合产生了一种精心设计的噪声模式：

```
              Z 轴方向
              ↑
     slice k  │  ██████████████  ←─ 平滑的噪声团
     slice k+1│  ░░░░░░░░░░░░░░  ←─ 完全不同的平滑噪声团
     slice k+2│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ←─ 又一种不同的平滑噪声团
              └──────────────── XY 平面
```

- **XY 内平滑**：每个 slice 上的噪声像一块平滑的"补丁"，没有尖锐的纹理，人眼难以察觉，也不容易被 denoising 算法去除（因为它看起来像自然的信号变化）
- **Z 方向剧变**：相邻 slice 的噪声"补丁"模式完全不同，打破了 3D 模型赖以建模的层间连续性
- **对 3D 卷积的致命影响**：3D 卷积核（比如 3×3×3）在 Z 方向上跨越的 3 个 slice 看到的是完全不一致的噪声模式，提取到的特征充满混乱信号

### 3.4 可微分频域滤波：实现端到端优化

传统频域滤波使用硬阈值（`torch.where`），不可微分，截止频率无法通过梯度优化。本方法使用 **sigmoid 软阈值** 替代：

```
硬阈值（不可微）：               sigmoid 软阈值（可微）：

M │                              M │
1 │      ┌──────────             1 │        ╱──────────
  │      │                         │      ╱
  │      │                         │    ╱
0 │──────┘                       0 │──╱
  └──────────── freq               └──────────── freq
      cutoff                           cutoff
  ∂M/∂cutoff = 0                  ∂M/∂cutoff ≠ 0
  (无法优化)                       (可通过梯度下降优化)
```

`sigmoid((freq - cutoff) / σ)` 在截止频率附近产生平滑过渡，对 cutoff 有明确的梯度，使得截止频率可以作为可学习参数参与端到端训练。

## 4. 方法总览

### 4.1 整体架构

```
Image x ──────────────→ NoiseUNet ──→ δ_raw (原始噪声)
[B, C, D, H, W]                          │
                                          │
                    GlobalLearnableCutoff  │
                    ┌──────────────────┐   │
                    │ z_logit (标量)    │   │
                    │ xy_logit (标量)   │   │
                    │                  │   │
                    │ sigmoid → range  │   │
                    │ → (z_c, xy_c)    │───┤
                    └──────────────────┘   │
                                          ▼
                              FrequencyDomainConstraint
                              ┌─────────────────────────┐
                              │ 1. FFT(δ_raw)           │
                              │ 2. M_z = σ((|f_z|-z_c)/σ│z)
                              │ 3. M_xy= σ((xy_c-r_xy)/σ│xy)
                              │ 4. fft × M_z × M_xy     │
                              │ 5. IFFT → δ_filtered     │
                              └──────────┬──────────────┘
                                         │
                                         ▼
                                   ROI Mask (可选)
                                         │
                                         ▼
                                  clamp(δ, -ε, ε)
                                         │
                                         ▼
                              perturbed = clamp(x + δ, 0, 1)
                                         │
                                         ▼
                              Surrogate Model (冻结)
                                         │
                                         ▼
                                    DiceCE Loss
                                    ╱         ╲
                            opt_unet.step()  opt_cutoff.step()
```

### 4.2 数据流概览

1. **输入**：3D 医学图像 `x [B, C, D, H, W]` + 分割标签 `y [B, D, H, W]`
2. **噪声生成**：NoiseUNet 以 `x` 为输入，输出与 `x` 同尺寸的扰动 `δ_raw`，通过 `tanh × ε` 约束到 `[-ε, ε]`
3. **截止频率生成**：GlobalLearnableCutoff 输出两个全局标量 `(z_c, xy_c)`，所有样本共享
4. **频域约束**：将 `δ_raw` 经 3D FFT 变换到频域，乘以由 `(z_c, xy_c)` 构建的可微分掩码，再 IFFT 回空间域
5. **ROI 聚焦**：可选地乘以 ROI 软掩码，使噪声集中在感兴趣区域（分割目标附近）
6. **代理评估**：将扰动图像送入冻结的代理分割模型，计算 DiceCE Loss
7. **优化**：通过 DiceCE Loss 的梯度同时更新 NoiseUNet 和截止频率参数

## 5. 核心组件详解

### 5.1 NoiseUNet — 噪声生成器

```python
class NoiseUNetWrapper(nn.Module):
    # 基于 MONAI 3D UNet，输入图像，输出同尺寸噪声
    # tanh 激活确保输出在 [-ε, ε] 范围内
    forward(x) → tanh(UNet(x)) × ε
```

**设计动机**：使用 UNet 而非随机噪声，是因为 UNet 可以基于图像内容生成**自适应的**噪声模式——不同的解剖结构会得到不同的扰动，更有效地破坏模型学习。

**架构**：`[16, 32, 64, 128]` 通道数的 4 层 3D UNet，使用 Instance Normalization 和 LeakyReLU。

### 5.2 GlobalLearnableCutoff — 全局可学习截止频率

```python
class GlobalLearnableCutoff(nn.Module):
    z_logit  = nn.Parameter(...)   # 1 个标量
    xy_logit = nn.Parameter(...)   # 1 个标量

    forward():
        z_c  = sigmoid(z_logit)  × (0.45 - 0.01) + 0.01   # ∈ [0.01, 0.45]
        xy_c = sigmoid(xy_logit) × (0.45 - 0.05) + 0.05   # ∈ [0.05, 0.45]
        return z_c, xy_c
```

**核心设计**：

- **全局共享**：整个数据集使用同一对 `(z_c, xy_c)`，不同于 per-sample 预测版本，避免了 OOM 问题
- **Logit 参数化**：在无约束实数空间存储参数，通过 sigmoid 映射到有效范围，保证梯度不会将参数推到无效区间
- **初始化对齐**：logit 的初始值经过反向计算，使得初始输出恰好等于 YAML 中配置的默认截止频率（z=0.1, xy=0.3），确保训练初始行为与静态版本一致

### 5.3 FrequencyDomainConstraint — 频域约束模块

这是方法的核心，实现了方向解耦的可微分频域滤波。

**可学习路径（learnable path）**：

```python
# 1. 3D FFT
noise_fft = fftn(noise, dim=(-3, -2, -1))

# 2. 构建 Z 轴高通掩码 M_z [1, 1, D, 1, 1]
#    sigmoid(正) → 1 (通过), sigmoid(负) → 0 (衰减)
freq_z_5d = |fftfreq(D)|.view(1, 1, D, 1, 1)
M_z = sigmoid((freq_z_5d - z_cutoff) / σ_z)

# 3. 构建 XY 低通掩码 M_xy [1, 1, 1, H, W]
#    注意符号相反：xy_cutoff - r_xy → 低于截止的通过
r_xy_5d = sqrt(fy² + fx²).view(1, 1, 1, H, W)
M_xy = sigmoid((xy_cutoff - r_xy_5d) / σ_xy)

# 4. DC 校正（保持均值稳定）
#    频域 DC 分量(频率=0)代表全局均值，固定衰减到 0.1
M_z[dc_position] *= correction_factor

# 5. 分离式应用（节省内存）
noise_fft = noise_fft * M_z   # 广播 [B,C,D,H,W] × [1,1,D,1,1]
noise_fft = noise_fft * M_xy  # 广播 [B,C,D,H,W] × [1,1,1,H,W]

# 6. IFFT 回空间域
filtered = ifftn(noise_fft).real
```

**分离式掩码的内存优势**：

M_z 仅依赖 Z 频率（形状 `[1,1,D,1,1]`），M_xy 仅依赖 XY 频率（形状 `[1,1,1,H,W]`）。两者先后独立应用，通过广播完成，**永远不需要物化完整的 [B,C,D,H,W] 掩码张量**，对 3D 医学图像的大体积数据节省显著内存。

**静态路径（static path）**：

当不使用可学习截止频率时，使用预计算的固定掩码（`torch.where` + 高斯衰减），缓存后直接复用。

### 5.4 SoftROIMask — ROI 感知掩码

```python
class SoftROIMask(nn.Module):
    # 1. 将分割标签二值化 (label > 0)
    # 2. 形态学膨胀 (max_pool3d)：扩大 ROI 范围
    # 3. 3D 高斯模糊：平滑边界
    # 4. 归一化到 [0, 1]
```

**动机**：噪声集中在分割目标区域及其周围，而不是浪费扰动预算在背景上。软边缘避免了硬边界带来的频域伪影。

### 5.5 LogitsDivergenceLoss — 频域分割差异损失

```python
class LogitsDivergenceLoss(nn.Module):
    # 计算干净图像与扰动图像经代理模型后的 logits 差异
    # 使用 FFT-L1 度量：对 logits 差异做 3D FFT，取幅值的 L1 范数
    # 返回负值（因为要最大化差异 = 最小化负差异）

    def forward(logits_clean, logits_noisy):
        diff = logits_noisy - logits_clean
        diff_fft = fftn(diff, dim=(-3, -2, -1))
        divergence = diff_fft.abs().mean()
        return -weight * divergence
```

**动机**：DiceCE Loss 仅衡量扰动图像的分割质量，而 logits divergence 直接度量"扰动前后分割结果的偏离程度"，提供更直接的优化信号来最大化分割破坏效果。

**为什么使用 FFT-L1**：在频域中度量 logits 差异而非空间域，是因为频域能更好地捕获结构性偏差——不仅关注逐像素的预测偏移，还关注预测结果在空间频率分布上的整体错乱程度。对 3D 医学图像而言，这意味着扰动不仅在局部破坏分割，还在全局的频率结构上瓦解了模型对解剖形态的理解。

## 6. 训练流程

### 6.1 交替优化框架

训练采用 S-step / N-step 交替优化策略：

```
for each epoch:
    for each batch:
        ┌─── S-step (Surrogate Step) ───────────────────────┐
        │ 目的：更新代理模型，使其在当前噪声下尽量"好"        │
        │                                                    │
        │ 1. 从 noise backend 读取已存储的噪声 δ             │
        │ 2. perturbed = x + δ                               │
        │ 3. logits = surrogate(normalize(perturbed))        │
        │ 4. loss = DiceCE(logits, y)                        │
        │ 5. opt_surrogate.step()  ← 最小化 loss             │
        └────────────────────────────────────────────────────┘
                              ↓
        ┌─── N-step (Noise Step) ───────────────────────────┐
        │ 目的：更新噪声生成器，使代理模型在噪声下"失败"       │
        │                                                    │
        │ 1. z_c, xy_c = GlobalLearnableCutoff()             │
        │ 2. δ_raw = NoiseUNet(x)                            │
        │ 3. δ = FreqConstraint(δ_raw, z_c, xy_c)           │
        │ 4. δ = δ × ROI_mask, clamp to [-ε, ε]             │
        │ 5. logits = surrogate(normalize(x + δ))  [冻结]    │
        │ 6. loss = DiceCE(logits, y)                        │
        │ 7. (+ optional: z_diversity, logits_divergence)    │
        │ 8. loss.backward()                                 │
        │ 9. opt_unet.step() + opt_cutoff.step()             │
        │ 10. 存储最终噪声到 noise backend                    │
        └────────────────────────────────────────────────────┘
```

### 6.2 对抗博弈的直觉

这是一个**对抗博弈**：

- **代理模型**努力学会在噪声数据上做好分割（S-step 最小化 loss）
- **噪声生成器**努力让代理模型的分割尽可能差（N-step 中代理冻结，噪声最大化同一 loss）

随着训练推进，代理模型变得越来越"强"，而噪声也变得越来越"狡猾"。最终生成的噪声能够对抗一个经过充分训练的代理模型——这意味着它对未知的下游模型也大概率有效。

### 6.3 截止频率的演化

训练过程中，全局截止频率 `(z_c, xy_c)` 会随梯度自适应调整：

- 如果 loss 需要更强的层间差异 → 梯度推动 `z_c` 降低（允许更多 Z 高频通过）
- 如果 loss 需要更平滑的层内噪声 → 梯度推动 `xy_c` 降低（截断更多 XY 高频）
- 每个 epoch 结束后记录当前截止频率值，用于监控训练状态
