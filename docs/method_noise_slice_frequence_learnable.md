## 1. 研究动机

### 1.1 问题背景：医学图像数据的隐私保护

医学图像数据（CT、MRI 等）包含大量患者隐私信息。当医疗数据集被公开发布或共享后，恶意方可能利用这些数据训练高精度的医学图像分割（Medical Image Segmentation, MIS）模型，进而在未经授权的情况下对患者影像进行自动化分析。这构成了严重的数据滥用风险。

**不可学习样本（Unlearnable Examples, UE）** 提供了一种数据层面的主动防御机制：在发布数据前，对每张图像施加人眼不可感知的微小扰动（perturbation），使得任何下游模型在这些"被保护"数据上训练后，**无法学到有效的分割能力**。

如附图所示，整体流程为：

```
┌──────────────────────────────────────────────────────────────────┐
│                        正常流程（无保护）                          │
│                                                                  │
│  MIS 数据集 ──→ 训练 MIS 模型 ──→ 测试：DSC = 82.18% ✓          │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                     UMed 保护流程                                 │
│                                                                  │
│  MIS 数据集 ──→ UMed 生成扰动 ──→ 受保护数据集                    │
│                                                                  │
│  受保护数据集 ──→ 训练 MIS 模型 ──→ 测试：DSC = 6.80% ✗          │
└──────────────────────────────────────────────────────────────────┘
```

- 在干净数据上训练的模型能够正确分割（DSC = 82.18%）
- 在受保护数据上训练的模型完全失效（DSC = 6.80%），近乎随机猜测
- 扰动幅度极小（ε = 4/255），人眼无法分辨原图与受保护图像的区别

### 1.2 核心攻击目标

本方法的两个核心攻击维度：

**（a）破坏层间一致性（Inter-slice Consistency Disruption）**

3D 医学图像的本质特征是相邻层（slice）之间存在强烈的空间连续性——解剖结构在 Z 轴方向上平滑过渡。3D 分割模型（如 3D U-Net）依赖这种层间一致性来建立体积化的语义理解。我们的方法通过优化噪声使得相邻层的扰动模式截然不同，从根本上打破模型对层间连续性的依赖。

**（b）最大化分割差异（Segmentation Divergence Maximization）**

扰动的最终目的是使分割模型在受保护数据上训练时输出完全错误的预测。我们通过两个互补的损失函数驱动噪声优化：
- **DiceCE Loss**：直接最大化代理模型在扰动图像上的分割误差
- **FFT-L1 Logits Divergence**：在频域中最大化干净图像与扰动图像之间的分割预测差异，迫使扰动在空间频率结构上全面瓦解模型的输出

## 2. 为什么针对 3D 医学图像

### 2.1 3D 医学图像的独特结构

与自然图像（2D）不同，3D 医学图像具有以下特性：

| 特性 | 说明 | 对 UE 方法的意义 |
|------|------|------------------|
| **层间连续性** | 相邻 slice 的解剖结构高度相似 | 这是模型的核心先验，破坏它可以瓦解 3D 学习 |
| **各向异性分辨率** | Z 轴分辨率通常远低于 XY 平面 | Z 轴信息更脆弱，更容易被扰动影响 |
| **体积语义** | 器官跨越多个 slice，模型需要 3D 上下文 | 层间不一致的扰动会破坏体积语义的完整性 |
| **数据量大** | 单个样本 [D, H, W] 体积庞大 | 需要内存高效的扰动生成策略 |

### 2.2 3D 模型的脆弱性分析

3D 分割模型（如 3D U-Net、VNet）通过 3D 卷积核学习体积特征。它们的关键假设是：

```
假设：Z 轴方向上的特征变化是平滑、可预测的

现实（被扰动后）：Z 轴噪声模式剧烈变化 → 3D 卷积提取到的特征充满伪影
                  → 模型学到的是噪声模式而非解剖结构
                  → 在干净测试数据上完全失效
```

关键洞察：**3D 模型的优势（利用层间信息）恰恰是其最大的脆弱点**。如果层间信息被污染，模型不仅无法受益，反而会被误导。

### 2.3 为什么 2D 方法不够用

传统 2D 不可学习样本方法（如对每个 slice 独立加噪）忽略了 Z 轴维度：

- 独立加噪可能仍保持层间统计一致性，3D 模型仍能提取有用特征
- 没有针对性地破坏层间关系，攻击效果有限
- 不考虑 3D 频谱特性，无法在损失层面度量空间频率结构上的偏离

## 3. 为什么在损失函数中使用频域度量

### 3.1 空间域度量的局限

如果仅用空间域的逐像素度量（如 L1/L2）来衡量"干净预测与扰动预测的差异"，优化器倾向于寻找局部的、稀疏的大偏差——比如在少数像素上产生极大的预测偏移。这种局部扰动：

- **容易被模型的鲁棒性机制吸收**：局部异常值可被 batch normalization、dropout 等机制削弱
- **不涉及全局结构**：不破坏模型对整体解剖形态的频率表征
- **对 3D 体积上下文影响有限**：3D 卷积可以从周围正常 slice 中"修复"局部异常

### 3.2 频域度量如何捕获结构性破坏

3D FFT 将 logits 差异分解为三个正交方向的频率成分 `(f_z, f_y, f_x)`。对 logits 差异做 FFT 再取 L1 范数（即 FFT-L1），等价于**在频谱空间中衡量预测偏离的全局分布**：

```
空间域度量（L1）：
  |logits_noisy - logits_clean|.mean()
  → 衡量"每个体素的预测偏了多少"
  → 局部、逐点

频域度量（FFT-L1）：
  |FFT(logits_noisy - logits_clean)|.mean()
  → 衡量"预测差异的频率能量分布"
  → 全局、结构性
```

FFT-L1 的独特优势：

- **全局性**：每个频率分量都是原始信号的全局加权求和，因此 FFT-L1 反映的是整个体积上的系统性偏差，而非局部异常
- **跨频率均衡**：L1 范数对所有频率分量平等地施加惩罚，迫使扰动在低频（整体形态）和高频（边界细节）上同时造成破坏
- **对 3D 结构天然敏感**：3D FFT 中的 Z 轴频率成分直接对应层间变化模式。最大化 Z 频率上的 logits 差异，等价于迫使扰动让模型在不同 slice 上产生不一致的预测——这正是破坏层间一致性的目标

### 3.3 FFT-L1 对 3D 医学图像的特殊意义

对于 3D 医学图像分割，模型的预测（logits）在空间频率上有明确的语义：

| 频率域 | 空间语义 | FFT-L1 的作用 |
|--------|----------|---------------|
| Z 轴低频 | 器官在层间的整体轮廓连续性 | 最大化差异 → 打断模型对"器官跨层连续"的预测 |
| Z 轴高频 | 相邻层间预测的变化细节 | 最大化差异 → 注入层间预测不一致 |
| XY 低频 | 单层内器官的大致位置和形状 | 最大化差异 → 让模型对器官位置产生整体偏差 |
| XY 高频 | 分割边界的精细度 | 最大化差异 → 模糊和错乱分割边界 |

通过 FFT-L1 同时在所有方向、所有频率上最大化 logits 差异，等价于全方位地瓦解模型在 3D 体积上的分割能力。

## 4. 方法总览

### 4.1 整体架构

```
Image x ──────────────→ NoiseUNet ──→ δ_raw (原始噪声)
[B, C, D, H, W]                          │
                                          ▼
                                    ROI Mask (可选)
                                          │
                                          ▼
                                   clamp(δ, -ε, ε)
                                          │
                                          ▼
                               perturbed = clamp(x + δ, 0, 1)
                                          │
                              ┌───────────┴───────────┐
                              ▼                       ▼
                    Surrogate(perturbed)      Surrogate(clean x)
                         [冻结]                    [冻结]
                              │                       │
                              ▼                       ▼
                         logits_noisy            logits_clean
                              │                       │
                              ▼                       │
                     ┌── DiceCE Loss                  │
                     │   (最大化分割误差)               │
                     │                                │
                     │        ┌────────────────────────┘
                     │        ▼
                     │   FFT-L1 Divergence Loss
                     │   (最大化频域 logits 差异)
                     │        │
                     ▼        ▼
                   Total Loss = DiceCE + FFT-L1
                              │
                              ▼
                     loss.backward()
                     opt_unet.step()
```

### 4.2 数据流概览

1. **输入**：3D 医学图像 `x [B, C, D, H, W]` + 分割标签 `y [B, D, H, W]`
2. **噪声生成**：NoiseUNet 以 `x` 为输入，输出与 `x` 同尺寸的扰动 `δ_raw`，通过 `tanh × ε` 约束到 `[-ε, ε]`
3. **ROI 聚焦**：可选地乘以 ROI 软掩码，使噪声集中在分割目标区域附近
4. **扰动图像构造**：`perturbed = clamp(x + δ, 0, 1)`
5. **代理模型推理**：冻结的代理分割模型分别对干净图像和扰动图像进行前向传播，得到 `logits_clean` 和 `logits_noisy`
6. **双损失优化**：
   - **DiceCE Loss**：衡量扰动图像分割的错误程度（最大化）
   - **FFT-L1 Logits Divergence**：衡量干净与扰动预测在频域的差异（最大化）
7. **反向传播**：两个 loss 合并后驱动 NoiseUNet 参数更新

## 5. 核心组件详解

### 5.1 NoiseUNet — 噪声生成器

```python
class NoiseUNetWrapper(nn.Module):
    # 基于 MONAI 3D UNet，输入图像，输出同尺寸噪声
    # tanh 激活确保输出在 [-ε, ε] 范围内
    forward(x) → tanh(UNet(x)) × ε
```

**设计动机**：使用 UNet 而非随机噪声，是因为 UNet 可以基于图像内容生成**自适应的**噪声模式——不同的解剖结构会得到不同的扰动，更有效地破坏模型学习。

**架构**：`[16, 32, 64, 128]` 通道数的 4 层 3D UNet，使用 Instance Normalization 和 LeakyReLU。

### 5.2 SoftROIMask — ROI 感知掩码

```python
class SoftROIMask(nn.Module):
    # 1. 将分割标签二值化 (label > 0)
    # 2. 形态学膨胀 (max_pool3d)：扩大 ROI 范围
    # 3. 3D 高斯模糊：平滑边界
    # 4. 归一化到 [0, 1]
```

**动机**：噪声集中在分割目标区域及其周围，而不是浪费扰动预算在背景上。软边缘避免了硬边界带来的伪影。

### 5.3 DiceCE Loss — 分割误差损失

```python
loss_seg = DiceCELoss(logits_noisy, y)
```

**角色**：这是不可学习样本优化的核心驱动力。DiceCE Loss 综合了 Dice Loss（衡量区域重叠度）和交叉熵损失（衡量逐像素分类），是医学图像分割的标准损失函数。

在本方法中，我们**最大化**该 loss——即让代理模型在扰动图像上的分割结果尽可能差。这等价于训练噪声让分割模型在预测正确的区域形状（Dice）和逐像素的类别概率（CE）上同时犯错。

### 5.4 FFT-L1 Logits Divergence — 频域分割差异损失

```python
class LogitsDivergenceLoss(nn.Module):
    # 使用 FFT-L1 度量：对 logits 差异做 3D FFT，取幅值的 L1 范数
    # 返回负值（因为要最大化差异 = 最小化负差异）

    def forward(logits_clean, logits_noisy):
        diff = logits_noisy - logits_clean          # [B, C, D, H, W]
        diff_fft = fftn(diff, dim=(-3, -2, -1))     # 3D FFT
        divergence = diff_fft.abs().mean()           # L1 of spectral magnitude
        return -weight * divergence                  # 取负 → 最大化差异
```

**角色**：这是方法的核心创新点，弥补了 DiceCE Loss 的不足。

DiceCE Loss 仅关注"扰动图像的分割结果有多差"，但不直接度量"扰动前后的预测到底差了多少"。FFT-L1 Divergence 通过在频域中计算 logits 差异的全局能量分布，直接最大化干净图像与扰动图像之间的分割预测偏离程度。

**为什么使用 FFT-L1 而非空间域度量**：频域度量能更好地捕获结构性偏差——不仅关注逐像素的预测偏移，还关注预测结果在空间频率分布上的整体错乱。对 3D 医学图像而言，这意味着扰动不仅在局部破坏分割，还在全局的频率结构上瓦解了模型对解剖形态的理解，尤其是层间一致性的破坏（Z 轴频率分量）。

### 5.5 双损失的互补关系

两个 loss 各有侧重，互为补充：

```
                     ┌─────────────────────────────────────────┐
                     │              Total Loss                 │
                     │  = DiceCE(noisy) + λ · FFT-L1-Div       │
                     └──────────┬──────────────────────────────┘
                                │
                ┌───────────────┼───────────────┐
                ▼                               ▼
          DiceCE Loss                    FFT-L1 Divergence
     "让分割结果尽量差"              "让预测偏离尽量大且全面"
                │                               │
                ▼                               ▼
     • 区域重叠度恶化           • 全频段（低频形态+高频边界）
     • 逐像素分类错误             均匀地最大化 logits 偏差
     • 直接对标分割任务指标       • Z 轴频率→破坏层间预测一致性
                                • XY 频率→破坏层内空间结构
```

- **DiceCE** 确保噪声能直接降低分割性能指标
- **FFT-L1** 确保噪声造成的破坏是全局的、结构性的、跨方向的——不留死角

## 6. 训练流程

### 6.1 交替优化框架

训练采用 S-step / N-step 交替优化策略：

```
for each epoch:
    for each batch:
        ┌─── S-step (Surrogate Step) ───────────────────────┐
        │ 目的：更新代理模型，使其在当前噪声下尽量"好"        │
        │                                                    │
        │ 1. 从 noise backend 读取已存储的噪声 δ             │
        │ 2. perturbed = x + δ                               │
        │ 3. logits = surrogate(normalize(perturbed))        │
        │ 4. loss = DiceCE(logits, y)                        │
        │ 5. opt_surrogate.step()  ← 最小化 loss             │
        └────────────────────────────────────────────────────┘
                              ↓
        ┌─── N-step (Noise Step) ───────────────────────────┐
        │ 目的：更新噪声生成器，使代理模型在噪声下"失败"       │
        │                                                    │
        │ 1. δ = NoiseUNet(x)                                │
        │ 2. δ = δ × ROI_mask, clamp to [-ε, ε]             │
        │ 3. logits_clean = surrogate(x)  [冻结, no_grad]    │
        │ 4. logits_noisy = surrogate(x + δ)  [冻结]         │
        │ 5. loss = DiceCE(logits_noisy, y)                  │
        │         + λ · FFT-L1-Div(logits_clean, logits_noisy)│
        │ 6. loss.backward()                                 │
        │ 7. opt_unet.step()                                 │
        │ 8. 存储最终噪声到 noise backend                     │
        └────────────────────────────────────────────────────┘
```

### 6.2 对抗博弈的直觉

这是一个**对抗博弈**：

- **代理模型**努力学会在噪声数据上做好分割（S-step 最小化 loss）
- **噪声生成器**努力让代理模型的分割尽可能差（N-step 中代理冻结，噪声最大化同一 loss）

随着训练推进，代理模型变得越来越"强"，而噪声也变得越来越"狡猾"。最终生成的噪声能够对抗一个经过充分训练的代理模型——这意味着它对未知的下游模型也大概率有效。

### 6.3 双损失的优化动力学

训练过程中两个 loss 共同驱动 NoiseUNet 的优化方向：

- **DiceCE 梯度**：告诉 NoiseUNet "在哪些区域、哪些类别上需要更大的扰动来恶化分割"——这是任务导向的信号
- **FFT-L1 梯度**：告诉 NoiseUNet "在哪些频率方向上，预测差异还不够大"——这是结构导向的信号，尤其会推动噪声在 Z 轴方向产生更强的层间不一致效应

两个梯度信号合力使得 NoiseUNet 学会生成既能直接降低分割精度、又能在频域结构上全面瓦解模型预测的扰动。
