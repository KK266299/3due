# 3DUE 噪声可视化方案

## 核心问题

你的噪声是 **3D 体数据** `[C, D, H, W]`，主要方法是 **破坏层间一致性（inter-slice consistency disruption）**。关键问题：

1. **可视化 3D 噪声还是 2D 切片？**
2. **如何直观展示"层间一致性被破坏"这一特性？**

---

## 结论先行

> **不需要做真正的 3D 渲染。2D 切片 + 沿深度轴的统计曲线就足以表达你的核心创新点。**

理由：
- 医学影像论文的读者习惯看 2D axial/coronal/sagittal 切片
- 你的核心创新点是 **深度方向（Z 轴）的切片间差异**，这用 1D 曲线（沿 Z 轴的相关性/差异度）比任何 3D 渲染都更清晰
- 真正的 3D volume rendering（如 VTK/Open3D）对噪声这种低幅值、无结构的信号效果很差——看起来像雾
- 你现有的 `spectral_visualizer.py` 已经有 inter-slice correlation 的可视化雏形

---

## 推荐的可视化方案

### 方案 A：多切片并列对比图（最核心，必做）

**目的**：直观展示相邻切片的噪声 pattern 差异

**布局**：

```
┌─────────┬─────────┬─────────┬─────────┬─────────┐
│ Slice z │Slice z+1│Slice z+2│Slice z+3│Slice z+4│
│  噪声   │  噪声   │  噪声   │  噪声   │  噪声   │
│ (BWR)   │ (BWR)   │ (BWR)   │ (BWR)   │ (BWR)   │
├─────────┼─────────┼─────────┼─────────┼─────────┤
│ Slice z │Slice z+1│Slice z+2│Slice z+3│Slice z+4│
│ 原图    │ 原图    │ 原图    │ 原图    │ 原图    │
├─────────┼─────────┼─────────┼─────────┼─────────┤
│Diff z→z+1│Diff z+1→z+2│Diff z+2→z+3│Diff z+3→z+4│统计信息│
│ 相邻差异 │ 相邻差异   │ 相邻差异   │ 相邻差异   │       │
└─────────┴─────────┴─────────┴─────────┴─────────┘
```

**关键点**：
- Row 1：连续 5 个切片的噪声（蓝白红 colormap，`[-ε, +ε]`）
- Row 2：对应的原始图像（灰度 / CT 窗宽窗位）
- Row 3：相邻切片噪声的**差异图** `|δ[z+1] - δ[z]|`（hot colormap）
- 对比实验：同时生成 `smooth` 模式和 `disrupt` 模式的噪声，smooth 模式下相邻切片噪声几乎相同，disrupt 模式下差异图应该非常亮

**适用场景**：论文 Figure 主图，展示方法的直觉


### 方案 B：层间相关性曲线（最重要的定量图，必做）

**目的**：用一条曲线定量展示整个体数据沿深度方向的噪声一致性

**内容**：

```
           Inter-Slice Noise Correlation Along Depth
    1.0 ┤
        │  ──── Smooth mode (baseline)
        │  ──── Disrupt mode (ours)
        │  ──── Random noise
    0.5 ┤  ──── No constraint (UNet basic)
        │
Pearson │
 Corr.  │
    0.0 ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
        │
   -0.5 ┤
        └────────────────────────────────────────
         0      20      40      60      80     D
                     Slice Index (z)
```

**计算方法**：
```python
# 对每一对相邻切片 (z, z+1)
correlations = []
for z in range(D - 1):
    s1 = noise[channel, z].flatten()
    s2 = noise[channel, z + 1].flatten()
    corr = np.corrcoef(s1, s2)[0, 1]
    correlations.append(corr)
```

**关键点**：
- X 轴：切片索引 z
- Y 轴：相邻切片的 Pearson 相关系数
- 多条线对比：`disrupt` vs `smooth` vs `random` vs `no_constraint`
- **disrupt 模式应显示接近 0 或负值的相关性**（层间噪声不相关/反相关）
- **smooth 模式应显示接近 1 的相关性**（层间噪声几乎相同）
- 可以额外画 mean ± std 作为阴影区域（多个样本的统计）

**适用场景**：论文 Figure 定量分析，最直接的证据


### 方案 C：XZ/YZ 截面图（展示深度方向的噪声结构，推荐）

**目的**：通过正交截面展示噪声在深度方向的变化特征

**布局**：

```
┌──────────────────────┬──────────────────────┐
│    XY 切片 (z=mid)   │    XZ 截面 (y=H/2)   │
│    噪声 [H × W]      │    噪声 [D × W]      │
│    (BWR colormap)     │    (BWR colormap)     │
├──────────────────────┼──────────────────────┤
│    YZ 截面 (x=W/2)   │   频谱对比 / 统计    │
│    噪声 [D × H]      │                      │
│    (BWR colormap)     │                      │
└──────────────────────┴──────────────────────┘
```

**关键点**：
- XZ 和 YZ 截面直接展示了噪声沿深度方向（Z 轴）的变化
- disrupt 模式下：XZ/YZ 截面应呈现**高频条纹状**（相邻行差异大）
- smooth 模式下：XZ/YZ 截面应呈现**平滑渐变**（相邻行相似）
- 这在你的 `spectral_visualizer.py` 中已有雏形（`visualize_noise_delta` 函数的 XZ/YZ 截面部分）

**适用场景**：论文 Figure 补充直觉，配合方案 A


### 方案 D：频谱分析对比图（展示频域特性，推荐）

**目的**：从频域角度解释为什么 disrupt 模式有效

**布局**：

```
┌────────────────────────┬────────────────────────┐
│  Z 轴功率谱 (1D 曲线)  │  XY 平面功率谱 (2D)    │
│  对比 disrupt/smooth   │  对比 disrupt/smooth   │
├────────────────────────┼────────────────────────┤
│  3D FFT 的 XZ 投影     │  频域能量分布饼图/条形图│
│                        │  (低频 vs 中频 vs 高频) │
└────────────────────────┴────────────────────────┘
```

**关键点**：
- Z 轴功率谱：disrupt 模式应在 **高频区（接近 Nyquist）** 有更高能量
- XY 平面功率谱：如果结合了 `noise_slice_frequence` 方法的 XY LOW-PASS 约束，XY 平面应集中在低频
- 对比不同方法的频谱差异

**适用场景**：论文 Figure 机理分析


### 方案 E：多方法对比大图（综合展示，论文核心图）

**目的**：一张图对比所有方法的噪声可视化效果

**布局**：

```
            Slice z    Slice z+1  |δ[z+1]-δ[z]|  XZ截面    Corr曲线
           ─────────  ─────────  ────────────  ─────────  ─────────
Random     │         │         │            │         │         │
           ├─────────┼─────────┼────────────┼─────────┼─────────┤
UNet       │         │         │            │         │         │
(basic)    ├─────────┼─────────┼────────────┼─────────┼─────────┤
Smooth     │         │         │            │         │         │
           ├─────────┼─────────┼────────────┼─────────┼─────────┤
Disrupt    │         │         │            │         │         │
(Ours)     ├─────────┼─────────┼────────────┼─────────┼─────────┤
Freq+Slice │         │         │            │         │         │

```

**每行一种方法，每列一种可视化角度**：
- Col 1-2：相邻两个切片的噪声（BWR）
- Col 3：相邻差异图（hot colormap）
- Col 4：XZ 截面图（BWR）
- Col 5：层间相关性曲线（mini 曲线图）

**适用场景**：论文的核心对比 Figure

## 为什么不需要 3D Volume Rendering

| 方面 | 3D 渲染 | 2D 切片 + 曲线 |
|------|---------|----------------|
| 直觉表达力 | 噪声是低幅值信号，3D 渲染后看不清楚 | 2D BWR colormap 非常清晰 |
| 层间差异表达 | 不直观，需要旋转才能看到 | 相邻切片并列 / XZ截面 / 曲线一目了然 |
| 论文惯例 | 医学影像论文极少用 3D 噪声渲染 | 标准做法 |
| 实现成本 | 需要 VTK/Open3D/mayavi | matplotlib 即可 |
| 可复现性 | 依赖渲染参数（transfer function等） | 确定性输出 |

**唯一需要 3D 的场景**：如果你想做一个 video/GIF 展示沿深度方向滚动的噪声变化，这很容易实现（逐帧保存 2D 切片然后拼接成 GIF），也不是真正的 3D 渲染。
